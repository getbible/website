# The Word. For the world.

Get Bible brings Scripture into the places people already read, learn, build and connect. At its core, it is a family of APIs that developers can use to put the Bible into applications of their own.

## Our purpose

Our mission is to make the Bible accessible throughout the world, in a powerful and practical way. We provide the data and tools that let programmers, churches, ministries and communities build experiences around Scripture.

An API can serve a verse in a website, a passage in a mobile app, a search result in a study tool, or source material for an AI assistant. Each integration is another opportunity to bring the Word to someone.

## Our next focus

The [Get Bible app](/project/app/) is under development. It currently uses Bible API v2. Our intended direction is to advance it to v3 and integrate dictionaries, commentaries and the wider study ecosystem, then work toward app-store and desktop distribution.

That is work to help shape and test, rather than a promise that those integrations or store releases are available today. Explore the source and contribute testing, accessibility feedback, platform expertise or implementation work.

## Open source and content rights

Code and data are available through the [Get Bible GitHub organization](https://github.com/getbible). Check the license in each repository and the metadata for each translation or study work you use. An open API is a delivery mechanism; it does not remove the attribution or reuse requirements of the underlying material.

All public questions go to the [central support desk](https://git.vdm.dev/getBible/support).
